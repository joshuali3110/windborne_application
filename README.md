# WindBorne Application

application for Windborne Systems' summer 2025 positions

## Tech Stack:

- Frontend: React.js, Leaflet.js, Vercel
- Backend: Python, Render

## Deployed At:

https://windborne-balloon-mapping.vercel.app/

## Running Locally

This is a two-part app — a Python/FastAPI backend and a React frontend — each with its own setup instructions:

- Backend: [back-end/README.md](back-end/README.md)
- Frontend: [balloon-mapping/README.md](balloon-mapping/README.md)

Set up the backend first (it requires Docker for a local Redis instance), then the frontend.
